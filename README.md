# Card Database Site (Vercel)

Structure:
- `public/index.html`  static front end
- `api/cards.js`, `api/filters.js`  serverless functions (Postgres queries)
- `lib/db.js`  shared connection pool

Deployed Site: https://tynmlptcg.vercel.app

Future plans:
Implement a deck building feature that allows a user to build and save decks.
Deck export feature to allow user to make a deck and bring it into a Tabletop Simulator online playable space of the game.
